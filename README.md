# Tu mine et tu craft

Prototype de jeu sandbox voxel 3D en vue à la première personne, en mode créatif.

## Jouer
Active **GitHub Pages** dans les paramètres du dépôt (Settings → Pages → Deploy from a branch → main / root), puis ouvre l'adresse publiée.

## Commandes PC
- **WASD** ou flèches : se déplacer
- **Souris** : regarder autour
- **Espace** : sauter
- **Clic gauche** : miner un bloc
- **Clic droit** ou **E** : placer un bloc
- **1 à 5** : choisir le bloc

## Commandes tactiles
- Joystick gauche : déplacement
- Glisser dans la zone droite : regarder
- Boutons : sauter, miner et placer
- Barre du bas : choisir le bloc

## Technologie
Three.js chargé depuis jsDelivr, JavaScript natif et GitHub Pages.
